Getting Started

Sentinel is a git-native orchestration harness designed for high-velocity engineering teams. This guide will help you configure your first project and understand the core architecture.

Prerequisites

  • Node.js 18.0.0 or higher
  • Git installed and configured
  • A modern terminal (we recommend iTerm2 or Alacritty)

Quick Init

The fastest way to scaffold a new Sentinel configuration is via the CLI. Run the following command in your project root:

$ npx sentinel-cli init --template default
warning

Configuration Warning

Do not commit your .sentinel.local.yaml file to version control. It may contain environment-specific secrets. Ensure it is added to your .gitignore.

Configuration Anatomy

A standard Sentinel deployment requires a master configuration file. Below is an example of a minimalist setup:

sentinel.yaml 
version: '1.0'
project:
  name: "demo-orchestration"
  environment: "production"

pipelines:
  - name: "build-and-deploy"
    trigger:
      branch: "main"
    steps:
      - run: "npm ci"
      - run: "npm run build"
