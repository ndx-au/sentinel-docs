Getting Started

Initialize your first Sentinel orchestration environment and understand the core workflow loop.

# Installation

Sentinel can be installed globally via your preferred package manager. We recommend using npm or yarn for the most seamless integration with existing CI/CD pipelines.

Terminal content_copy 
# Install globally via npm
npm install -g sentinel-cli

# Verify installation
sentinel --version
v1.2.0
lightbulb
Pro Tip: Local Installations While global installation is convenient for quick starts, we highly recommend installing Sentinel as a devDependency in your project for team consistency and reproducible builds.

# Initialization

Once installed, navigate to your project root and initialize a new Sentinel configuration. This will generate a sentinel.yaml file that dictates your orchestration logic.

sentinel.yaml content_copy 
version: "1.0"
project:
  name: "my-service"
  environment: "development"

workflows:
  build:
    steps:
      - name: "Compile assets"
        run: "npm run build"
      - name: "Run tests"
        run: "npm test"
