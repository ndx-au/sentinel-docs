Getting Started

A brief guide to orchestrating your first git-native deployment with Sentinel.

Before we begin, ensure you have the necessary prerequisites installed on your local machine. Sentinel relies heavily on standard git workflows, so a solid understanding of branch management will serve you well as we progress through these initial steps.

Installation

We recommend installing the Sentinel CLI via our official brew tap for MacOS users, or via the provided installation script for Linux environments. Windows support is currently handled via WSL2. 

brew tap sentinel/core
brew install sentinel-cli

— Note: If you encounter permission errors during installation, ensure your user has appropriate rights to the designated bin directory, or consider running the installation script with elevated privileges as detailed in our troubleshooting guide.

Initialization

Once installed, navigate to your project directory and initialize the Sentinel harness. This command will create a `.sentinel` directory containing the base configuration schema. 

cd /path/to/your/project
sentinel init --template=standard
