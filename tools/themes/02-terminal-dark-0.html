Getting Started

Initialize Sentinel in your environment and run your first orchestration harness.

Installation

Sentinel is distributed as a single static binary. Download the latest release for your platform.

bash
curl -sSL https://install.sentinel.dev | bash
lightbulb

Pro Tip: Path Configuration

Ensure that ~/.sentinel/bin is in your system's PATH to execute commands globally without specifying the absolute path.

Initialization

Navigate to your project root and initialize a new Sentinel configuration file. This will create a .sentinel.yaml file.

bash
$ sentinel init --template minimal
Initialized empty Sentinel repository in /path/to/project
WARN: No upstream Git remote detected.

Configuration Structure

The configuration file defines your orchestration jobs, environment variables, and trigger conditions.

yaml
version: "1.0"
project:
  name: "core-services"
  
harness:
  default_runner: "ubuntu-latest"
  stages:
    - build
    - test
    - deploy
