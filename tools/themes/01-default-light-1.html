Getting Started with Sentinel

calendar_today Updated Oct 24, 2023

Welcome to Sentinel, the git-native orchestration harness designed for modern engineering teams. This guide will walk you through the essential steps to install, configure, and run your first Sentinel workflow.

What is Sentinel?

Sentinel bridges the gap between infrastructure as code and dynamic orchestration. By treating your Git repository as the immutable source of truth, Sentinel ensures that every deployment, configuration change, and orchestration sequence is versioned, auditable, and repeatable.

lightbulb

Tip

Sentinel uses Git as the source of truth for your orchestration logic.

To get started immediately, you can install the Sentinel CLI using our automated installation script. This will download the latest binary for your architecture and place it in your system's PATH.

Installation

bash 
curl -sSL https://sentinel.sh/install | sh

Once installed, verify the installation by running sentinel version in your terminal. You are now ready to initialize your first project workspace.
