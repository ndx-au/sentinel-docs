Documentation page for Sentinel Docs: same docs reading layout, showing the "Paper & Ink" editorial theme variant.

PLATFORM: Desktop, single screen, documentation reading layout.

PAGE STRUCTURE:
1. Sticky top navbar in warm cream (#f7f2e9) with a 1px ink bottom rule: left serif wordmark "Sentinel Docs" in near-black ink; center-right Theme dropdown showing "Paper & Ink" styled as an understated bordered select; right GitHub link in small caps.
2. Left sidebar on cream: doc nav in serif-friendly typography, active item "Getting Started" in ink with an underline rather than color.
3. Main content: doc title set in a literary serif (like Source Serif), drop-cap-free but generous first paragraph, body in warm black on cream, code blocks still dark ink (#2b2620) with warm amber syntax accents, blockquote-style tip callout with an em-dash lead.
4. Footer pager: understated text links with underline on hover.

Theme concept: editorial book-like reading theme — serif headings, warm paper, minimal color (ink + one rust accent #b4552d used only for inline links). Feels like a well-typeset manual.

DO NOT INCLUDE: marketing hero, stock photography, bright accent colors, glassmorphism, heavy shadows, colorful badges.
